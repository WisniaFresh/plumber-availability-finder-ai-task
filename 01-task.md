# Your role (fullstack developer)

You are joining a startup that is building booking platform for clients that had emergencies and need plumbing services as soon as possible.

Treat the interviewer as your product manager.

## Your task

Implement an **availability engine** so the user can find the closest available 1-hour timeslot that can be booked. When timeslot is found, and user clicked `Accept` make sure other users cannot book it anymore.
