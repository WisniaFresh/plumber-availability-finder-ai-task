## User journey:

- The user enters the main page.
- The user clicks the big `Find closest booking` button at the top.
- The user sees a **loading state** on the button while the engine is working.
- When response is ready, the user is redirected to the results page.
- The results page displays the proposed booking using **real data from the backend** (company, employee, start time, end time).
- User clicks `Accept` button from this moment other users can't book the same timeslot anymore.
- Other users should not be able to book the same timeslot anymore.
- User stays on the same page and sees confirmation message "Booking confirmed!"
